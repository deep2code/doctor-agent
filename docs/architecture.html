publicPaths 豁免清单

  • 免鉴权 + 免限流：/、/index.html、/map、/stats、/robots.txt、/sitemap.xml、/llms.txt、/health
  • 不豁免：/app、懒加载 JS 资源、/media/* 与所有 API —— 设了 API_KEY 时浏览器直连网页版会拿到 401，需走带 token 的反代或客户端
