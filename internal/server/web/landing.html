说不清哪里痛？

指一指，就够了

绝大多数人描述不清部位——一句"肚子痛"背后可能是十几种完全不同的情况。切换性别与正 / 背面，直接点击不舒服的位置，医答帮你把问题问清楚。

点击身体上不舒服的位置

为什么"指位置"比"说"更靠谱

  • 腹部按九分法区分，右下腹痛与右上腹痛指向的病因完全不同，靠语言很难说准。
  • 腰、背、臀的疼痛常被笼统称"腰痛"，但下背、骶尾部、肾区的处理路径差别很大。
  • 选好部位后，问题会自动带上准确描述进入咨询台，省去反复追问的几轮对话。
